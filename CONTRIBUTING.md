# Contributing Guidelines

Thank you for your interest in contributing to this project!

## How to Contribute

1. Fork the repository
2. 2. Create a new branch for your feature or bug fix
   3. 3. Make your changes and commit them with clear messages
      4. 4. Submit a pull request describing your changes
        
         5. ## Code of Conduct
        
         6. Please be respectful and follow our [Code of Conduct](CODE_OF_CONDUCT.md).
        
         7. ## Reporting Issues
        
         8. Please use the GitHub Issues tracker to report bugs or request features.

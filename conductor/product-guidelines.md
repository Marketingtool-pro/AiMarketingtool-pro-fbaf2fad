# Product Guidelines

## UI/UX
- Follow Material Design for Android and Human Interface Guidelines (HIG) for iOS.
- Prioritize visual polish, consistent spacing, and smooth animations.
- Ensure high-contrast colors and proper accessibility labels.

## Code Style
- Follow the project's established conventions (TypeScript, React Hooks).
- Use modular components and functional patterns.
- Keep components clean and focused on a single responsibility.

## Assets
- Use high-quality SVG or optimized images.
- Prefer icons from the established libraries (Lucide, Expo Icons).

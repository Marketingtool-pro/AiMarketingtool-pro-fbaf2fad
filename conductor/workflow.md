# Workflow

## Development Loop
1.  **Exploration**: Understand the requirements and existing codebase.
2.  **Planning**: Use `/plan` to define tasks.
3.  **Implementation**: Write and verify code.
4.  **Testing**: Run tests on target platforms (iOS/Android/Web).
5.  **Review**: Perform a code review with Conductor.

## Common Commands
- `npm start`: Start the Expo dev server.
- `npm run ios`: Run on iOS simulator/device.
- `npm run android`: Run on Android emulator/device.
- `npm run web`: Run in web browser.

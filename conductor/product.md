# Product Definition

## Overview
- Project Name: marketingtoolapp
- Version: 1.3.3
- Objective: A marketing tool app built with Expo and React Native.

## Core Features
- User Authentication (Firebase, Appwrite)
- Navigation (React Navigation)
- Data Persistence (MMKV, Appwrite)
- Animations (Lottie, Reanimated, Skia)
- Real-time Features (Firebase, Appwrite)

## Target Audience
- Marketers, business owners, and individuals needing marketing tools.

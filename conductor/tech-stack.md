# Tech Stack

## Core
- **Framework**: Expo (React Native)
- **Language**: TypeScript
- **State Management**: Zustand
- **Navigation**: React Navigation (Native Stack, Bottom Tabs)

## Backend & Services
- **Auth/Cloud**: Firebase (@react-native-firebase/app, auth)
- **Database/Platform**: Appwrite (react-native-appwrite)
- **Storage**: react-native-mmkv

## UI & Graphics
- **Icons**: lucide-react-native, @expo/vector-icons, react-native-vector-icons
- **Graphics**: @shopify/react-native-skia, three.js
- **Animation**: react-native-reanimated, lottie-react-native
- **Components**: react-native-svg, expo-blur, expo-linear-gradient, react-native-screens

## Utilities
- **Haptics**: expo-haptics
- **Permissions/Sensors**: expo-sensors, expo-location, expo-media-library
- **Sharing**: expo-sharing, expo-image-picker, react-native-view-shot
